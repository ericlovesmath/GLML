# GLML (OpenGL Meta Language)

GLML is a functional domain-specific language for writing fragment shaders, targeting GLSL!

- Docs: [www.glml-lang.com](https://www.glml-lang.com)
- **Try GLML Playground:** [playground.glml-lang.com](https://playground.glml-lang.com)
